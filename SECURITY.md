# Security policy

This repository is a bounded public engineering reference for MachineOutcome. It is not the private production system and should not contain production credentials, customer data, private provider configuration, or unpublished commercial logic.

## Reporting

If you find a security issue in this public reference, do not publish secrets, credentials, customer data, or exploit details in a public issue.

Report it to the repository owner using the contact email linked from the GitHub profile and include:

- repository and exact commit/ref;
- affected file or behavior;
- impact;
- minimal reproduction steps;
- whether any secret or private data may have been exposed.

Do not send real credentials or customer data as part of a report.

## Scope

Security claims are limited to the code and tests visible in this repository. This policy does not imply that the private production system has the same architecture, dependencies, deployment surface, or threat model.
